Choosing components is a very important part of your design; in fact, it's the first thing you should do! Below we've created a list of things that you need for your bot, with links to each page to learn more about them! 

We've also assembled a list of components we think you should use for your first bot. Jump to that [here](#our-recommended).

### Anatomy of a Robot
- 2x [Drive Motors](/components/drivemotors)
- [Dual Drive ESC](/components/escs)
- [Weapon Motor](/components/weaponmotors)/[Servo](/components/servos)
- [Weapon ESC](/components/escs)
- [Battery](/components/powersystem)
- [Power Switch](/components/powersystem)
- [Status Light](/components/powersystem)
- [Transmitter/Reciever](/components/txrx)

### Our Recommended:
We chose medium-tier components that balance ease of use with cheapness; you are free to use cheaper components if you so wish, but we believe this will give you the best first experience.
- 2x Repeat Brushed Mini Pros
- 1x Repeat Budget Dual Brushed ESC
- 1x Repeat 2822 Mk3 Weapon Motor
- 1x Robodome 35A Weapon ESC
- 2x Gaoneng 380mAh 3S Li-Po Battery
- 1x Fingertech Switch
- 1x Tiny's LED 3-6S LED
- 1x Repeat FS2A Reciever
- 1x Flysky FS-i6X Transmitter
