Competitions are divided into weight classes; a robot only ever fights a robot of its own weight class. The most common weight classes are listed below.

| Item              | Weight |                                                                        Description | Price(USD) |
| :---------------- | :----: | ---------------------------------------------------------------------------------: | :--------- |
| Fairyweight       |  150g  |  The smallest active weight class; equally surprisingly expensive and destructive. | \~$200     |
| Plastic Antweight |   1lb  |            The cheapest weight class and best place for new builders to start off. | \~$140     |
| Antweight         |   1lb  |                                          A very destructive, yet affordable class. | \~$220     |
| Beetleweight      |   3lb  | The best balance between affordability and competitiveness for long-term builders. | \~$500     |

<Aside title='Plastic Antweight'> You'll notice there are two weight classes at 1lb; the difference is that *Plastic* Antweight limits the materials you can use to a set list of 3D-Printing Filaments; most commonly PLA+. This drastically reduces price. </Aside>

Most competitions will run a mix of the weight classes listed above, however bigger competitions will run larger; NHRL runs 3lb, 12lb, and 30lb, while BattleBots runs 250lb.
